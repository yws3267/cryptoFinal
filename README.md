# 암호학의 역사 (History of Cryptography)

고대부터 현대까지 암호학의 흐름을 **타임라인**과 **인터랙티브 시뮬레이터**로 배우는
멀티 페이지 교육용 웹사이트입니다. 프레임워크·빌드 과정 없이 순수
**HTML · CSS · JavaScript** 로만 구현했습니다.

---

## 실행 방법

별도 설치가 필요 없습니다.

1. 아래 13개 파일을 **같은 폴더**에 내려받습니다. (서로 상대경로로 참조합니다.)
2. `index.html` 을 웹 브라우저로 엽니다.

> 모든 파일이 한 폴더에 함께 있어야 `shared.css`, `index.js` 등이 정상적으로 연결됩니다.

---

## 페이지 구성

| 페이지     | 파일              | 설명                                                 |
| ---------- | ----------------- | ---------------------------------------------------- |
| 홈         | `index.html`      | 암호학 소개 + 시대별 박스(클릭 시 타임라인으로 이동) |
| 타임라인   | `timeline.html`   | 고대·중세·근현대·현대 4구간 연표, 시대별 카드        |
| 시뮬레이션 | `simulation.html` | 8개 암호 알고리즘 인터랙티브 시뮬레이터              |
| 팀 소개    | `about.html`      | 제작 팀 정보                                         |

## 주요 기능

- **타임라인**: 노드 클릭으로 시대별 섹션 전환, URL 해시(`#ancient-sec`)로 특정 시대 바로 열기
- **암호 시뮬레이터 8종**
  - 고대: 스키테일(전치), 카이사르(치환)
  - 중세: 알베르티(회전 원판), 비즈네르(타뷸라 렉타)
  - 현대: DES, AES, RSA
  - 해시: SHA-256
- **알베르티 회전 원판**: 슬라이더로 키를 돌리면 안쪽 원판이 실시간 회전
- **비즈네르 타뷸라 렉타**: 입력에 따라 키 행·평문 열·교차 칸이 실시간 하이라이트
- **DES·AES Hex 입력 가이드**: 필요한 글자수만큼 회색 점을 깔고 입력 시 채워짐
- **사이드바 토글**: 접힘 상태를 `localStorage`에 저장해 새로고침 후에도 유지

## 사용 기술 / JavaScript 핵심

순수 자바스크립트로 다음 개념들을 활용했습니다.

- **DOM 조작**: `getElementById`, `querySelectorAll`, `createElement`, `textContent`, `innerHTML`
- **이벤트**: `addEventListener`, 인라인 `oninput`, 커스텀 이벤트 `dispatchEvent(new Event('input'))`
- **상태 토글**: `classList.add / remove / toggle`, `dataset`
- **문자열·배열 메서드**: `split` · `map` · `join`, `padStart`, `slice`, `Set`
- **수학·비트 연산**: 모듈러 연산(`% 26`), 진법 변환(`parseInt(h,16)`, `toString(2)`),
  비트 시프트·회전(`>>>`, `<<`, `^`, `|`) — DES·AES·SHA-256 구현
- **삼각함수 좌표 계산**: `Math.cos / Math.sin` 으로 알베르티 원판 글자 배치
- **브라우저 저장소**: `localStorage` 로 UI 상태 유지
